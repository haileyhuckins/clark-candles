# Clark Candles LLC

A responsive website project for Clark Candles LLC, a fictional family-owned candle business based in San Dimas, California.

## About the Website

The website was created using HTML and CSS and follows a responsive float-based grid layout.

### Features

* Navigation menu
* Welcome section
* Four-column feature section
* Three-column product gallery
* Two-column About Us section
* One-column Products section
* Contact form
* Responsive mobile layout
* Custom candle business images

## Technologies Used

* HTML5
* CSS3
